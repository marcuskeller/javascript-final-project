Este site é um repositório de atividades de programação em HTML, CSS e JavaScript, criado pela turma de ADS de 2026 para ajudar alunos a se aprofundarem e entenderem as tecnologias usadas no dia a dia.

HTML

O HTML organiza o conteúdo em elementos (tags como <p>, <img>, <form>), montando a estrutura da página antes de qualquer cor ou comportamento. Pense no corpo humano: é o esqueleto, que dá forma e sustenta cada parte.

Documentação MDN - HTML

CSS

O CSS usa seletores e propriedades (cor, espaçamento, tamanho, fonte) pra estilizar os elementos do HTML, transformando a estrutura simples em algo bonito de se ver. É a pele: cobre o esqueleto e dá cor, textura e aparência ao corpo.

Documentação MDN - CSS

JavaScript

O JavaScript usa variáveis, funções e eventos pra validar um formulário, reagir a um clique e dar vida a tudo que o HTML e o CSS construíram. É o cérebro: pensa, decide e reage a estímulos.
