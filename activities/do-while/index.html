Teoria do Laço Faça...Enquanto

O laço Do...While (faça...enquanto) executa o bloco de código pelo menos uma vez, e só depois testa a condição para decidir se repete. Útil quando a primeira execução precisa acontecer sempre.

Quando usar no dia a dia

  • Pedir uma senha até o usuário digitar algo válido (o prompt precisa aparecer ao menos 1 vez)
  • Rodar pelo menos uma rodada de um jogo antes de perguntar se quer jogar de novo
  • Mostrar um menu de terminal que sempre aparece ao menos uma vez, mesmo sem input ainda
