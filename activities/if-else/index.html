Estruturas Condicionais Se...Senão

Teoria da Estrutura Se

A estrutura SE (if/else) testa uma condição: se ela for verdadeira, executa um bloco de código; senão (else), executa outro. Dá pra encadear várias condições com else if.

Quando usar no dia a dia

  • Validar se um formulário foi preenchido corretamente antes de enviar
  • Verificar se um usuário tem permissão antes de mostrar uma página
  • Decidir o valor do frete dependendo do total da compra
