Estruturas de Repetição Para

Teoria do Laço Para

O laço For (para) repete um bloco de código um número definido de vezes, controlando em uma única linha a inicialização, a condição de parada e o incremento da variável de controle.

Quando usar no dia a dia

  • Percorrer os itens de uma lista de produtos e calcular o total
  • Gerar uma tabela de multiplicação
  • Criar elementos repetidos numa página, como os cards de uma galeria
