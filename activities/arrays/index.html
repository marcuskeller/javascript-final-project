Estruturas de Coleções Arrays(Vetores)

Teoria

Arrays (vetores) guardam múltiplos valores em uma única variável, acessados por índice (posição). Permitem percorrer, somar, ordenar ou comparar vários dados sem precisar criar uma variável separada para cada um.

Quando usar no dia a dia

  • Lista de produtos de um carrinho de compras
  • Notas de alunos de uma turma, pra calcular a média
  • Lista de tarefas de um to-do list
